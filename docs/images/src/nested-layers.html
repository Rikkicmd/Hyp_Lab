Settings that make nesting work (set by scripts 04 and 07)

WhereSettingWhy
L0Set-VMProcessor -ExposeVirtualizationExtensions $trueLets HV01 run a hypervisor. The VM must be off when this is set.
L0Static memoryDynamic memory and runtime resize aren't supported for nested hosts
L0-MacAddressSpoofing OnL2 VM frames leave through HV01's vNIC with their own MACs
L0-DeviceNaming OnThe guest sees "Mgmt/Storage/Cluster" as NIC names
L1New-VMSwitch -EnableEmbeddedTeamingProduction-style SET switch shared with the management OS

Known nested limits

No live migration or saved state of HV01 itself, so lab checkpoints power the lab off first
No IOMMU or full VBS inside L1, so HGS attestation may report unhealthy
L2 performance is lower. Fine for training, not supported for production.
